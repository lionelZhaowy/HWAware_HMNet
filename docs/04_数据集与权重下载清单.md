# 数据集、元数据与权重下载清单

核查日期：2026-09-15。本轮**未下载数据、元数据或权重**；只查看官方页面、GitHub发布资产清单与HTTP HEAD响应。下面供你决定数据集、磁盘目录和下载范围。容量是压缩包/权重本身，解压、预处理副本、训练输出另需空间；MiB/GiB分别按1024²/1024³字节计算。

## 1. 下载范围如何选择

| 目标 | 数据 | 权重与配置 |
|---|---|---|
| 原HMNet检测基线 | GEN1 DAT事件和bbox标注，配套meta | GEN1 B3或B3 TBPTT，与对应配置配对 |
| 原HMNet分割基线 | DSEC-Semantic事件、图像、11类标注，配套meta | DSEC B3事件模型；官方发布列表没有DSEC RGB融合权重 |
| 合成数据深度基线 | Eventscape事件/帧/深度压缩包，配套meta | Eventscape B3或B3 fuse_rgb |
| 真实场景深度基线 | MVSEC HDF5事件/图像及深度GT | MVSEC B3或B3 fuse_rgb；元数据需本地生成 |

若先做单任务冒烟，可以先准备相应测试序列和匹配权重；届时需要单独的smoke文件列表/配置。**默认预处理脚本与训练配置会遍历预设的完整序列集合，不能直接把缺文件的部分下载目录当成完整数据集运行。**正式多任务改造前仍按规划补齐所需任务的数据与基线。

## 2. GEN1：目标检测

- [Prophesee官方数据申请/下载页](https://www.prophesee.ai/2020/01/24/prophesee-gen1-automotive-detection-dataset/)：页面下方有下载表单，需用户按要求填写；本轮未代填或提交。
- 当前HMNet数据路径使用原始`*_td.dat`事件和对应bbox的`.npy`标注，包含train/val/test。获取原始DAT版本，现成体素/事件立方体HDF5不能直接代入该读取路径。
- 原始包体积在表单发放链接后确认；此处不推算解压与预处理空间。

HMNet元数据：

- [gen1_train_meta.tar](https://github.com/hamarh/HMNet_pth/releases/download/v0.1.0/gen1_train_meta.tar)（1336.19 MiB）。
- [gen1_valtest_meta.tar](https://github.com/hamarh/HMNet_pth/releases/download/v0.1.0/gen1_valtest_meta.tar)（823.33 MiB）。

建议原始文件目录：`experiments/detection/data/gen1/source/`；预处理布局见[检测README](../experiments/detection/README.md)。
